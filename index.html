How It Works

A Hopfield Network stores patterns as stable energy minima. Given a noisy or partial input, neurons update asynchronously until the network settles into the nearest stored memory — recovering the original from corruption.

Weights are set by Hebbian learning: neurons that fire together wire together. The energy function E = −½ sᵀWs decreases monotonically at every update, guaranteeing convergence. Theoretical capacity is ≈ 0.138 × N patterns — beyond this, spurious attractors appear and recall degrades.
